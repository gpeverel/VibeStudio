  Окна 1440×900 (720×406 CSS px) и 1000×720 (500×316) — по 340 из 340. Всего 1050 из 1050.

- **Что проверено при 200%:**
  - **Tab.** Каждый элемент в фокусе виден целиком и с индикатором фокуса.
  - **Колесо мыши.** Прокручивает основную область и содержимое окон.
  - **Поля.** Принимают ввод с клавиатуры.
  - **Кнопки.** Основные действия и кнопки подвала окон проверены пробным нажатием Playwright `click({ trial: true })`.
- **Граница `click({ trial: true })`.** Пробное нажатие проверяет только *возможность* нажатия. Playwright прокручивает элемент в видимую область и убеждается, что тот виден, неподвижен, включён и не перекрыт другим элементом в точке нажатия. Само нажатие не выполняется. Поэтому при 200% не проверены срабатывание обработчика и результат действия. Активация Enter или пробелом при 200% тоже не проверялась.
- **Выполнение действий** (настоящие нажатия мышью и клавишами) проверяют сценарии `suite5`, `suite6` и `tests/ui7` (`b01`, `b02`, `a09`, `ax`, `native`) — только при масштабе 100%.
- **Проверки репозитория при исходной передаче Claude.** По отчёту исполнителя, `test:node` пройден. `typecheck`, `lint`, `check:boundaries`, `test`, `build` и `smoke` тогда не запускались: в его рабочей копии не было `node_modules`. Проверки после переноса приведены отдельно ниже.

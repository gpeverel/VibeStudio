# Дизайн-контракт

Единственный источник токенов — `src/renderer/styles/tokens.css`. Компоненты используют только `var(--*)`; цвета, отступы, радиусы и длительности «по месту» запрещены. Новый токен добавляется в этот файл и описывается здесь.

## Принципы

- Минимализм: нейтральные поверхности, один сдержанный акцент `--color-accent`, щедрые отступы.
- Без градиентов, декоративных теней, иконок-«искр», эмодзи в кнопках и пустых героев вида «Welcome».
- Изменения в diff передаются полосой слева (`--color-success` / `--color-danger`) и знаком «+» / «−»; фон изменённой строки — `--color-surface-sunken`, отдельных цветов фона нет.
- Статус всегда передаётся текстом или иконкой с подписью, а не только цветом (`--color-success`, `--color-warning`, `--color-danger`).
- Анимации не длиннее 150 мс (`--duration-fast`, `--duration-base`); при `prefers-reduced-motion` длительность обнуляется.
- Светлая и тёмная темы переключаются по `prefers-color-scheme` на уровне токенов.
- Видимый фокус клавиатуры: контур `--color-focus-ring`; основные действия доступны без мыши.
- Неподтверждённое не выглядит успехом: «неизвестно», «не подтверждено», «устарело», «не проверено» показываются нейтральным или предупреждающим значком с подписью, не зелёным.
- Размер текста: пояснения, причины недоступности действий и сообщения об ошибках не меньше `--font-size-sm` (12 px). `--font-size-xs` (11 px) только для коротких метаданных: время, счётчики, номера строк, ветка рядом с проектом. Важный текст переносится, а не уменьшается.
- Недоступное действие не исчезает молча: рядом текстом указана причина, граница кнопки пунктирная.

## Поля ввода

Границы input, select, textarea, поля сообщения и сегментного переключателя используют `--color-border-strong`: контраст не ниже 3:1 с `--color-bg`, `--color-surface` и `--color-surface-sunken` в обеих темах. Остальные разделители, карточки и кнопки сохраняют `--color-border`. Фокус — контур `--color-focus-ring` со смещением 2 px, граница не меняется. Недоступное поле — пунктир `--color-border`. Токен не используется как цвет текста, значка, заливки или фокуса. Нативные флажки и переключатели рисует система (`accent-color`, `color-scheme`).

## Токены

| Группа | Токены |
|---|---|
| Цвет | `--color-bg`, `--color-surface`, `--color-surface-sunken`, `--color-border`, `--color-border-strong`, `--color-text`, `--color-text-muted`, `--color-accent`, `--color-accent-contrast`, `--color-focus-ring`, `--color-scrim`, `--color-success`, `--color-warning`, `--color-danger` |
| Шрифт | `--font-sans`, `--font-mono`, `--font-size-xs…xl` (11/12/13/15/20 px), `--line-height-tight`, `--line-height-base`, `--font-weight-*` |
| Отступы | `--space-1…8` (4/8/12/16/24/32 px) |
| Скругления | `--radius-sm` (4 px), `--radius-md` (8 px) |
| Движение | `--duration-fast` (80 мс), `--duration-base` (150 мс), `--easing` |

Контраст текста и акцента проверяется вручную при добавлении компонентов (цель — WCAG AA, 4.5:1 для обычного текста); автоматическая проверка в этап 0A не входит.

## Ввод сообщений

Return отправляет сообщение, Shift+Return переносит строку; во время ввода через IME Return не отправляет. Подсказка видна рядом с полем. Высота поля растёт по содержимому до предела, затем появляется прокрутка внутри поля.

## Размер окна

Минимальный размер окна задан в `src/main/index.ts`: `minWidth: 640`, `minHeight: 480`. Это размер окна целиком, а не области содержимого: у стандартной рамки macOS область содержимого ниже на высоту заголовка (около 28 px, зависит от системы). Ширина меньше 800 px: панели открываются поверх, по одной.

Минимум 640×480 действует и при увеличенном масштабе интерфейса: при 200% текст, поля, основные действия и кнопки окон доступны прокруткой и клавиатурой, уменьшать масштаб не требуется. Если ширина области меньше 400 CSS px (минимальное окно при масштабе от 175%), раскладка не ниже 440 CSS px, а окно прокручивается целиком. Текстовое поле, получившее фокус, докручивается в видимую область. Область diff в ревью не ниже 160 CSS px; если места не хватает, прокручивается страница ревью. Для удобной работы при 200% рекомендуется окно от 1280×960; это рекомендация, а не минимум.

## Окна и панели поверх

Модальное окно и панель, открытая поверх, имеют `role="dialog"`, `aria-modal="true"` и заголовок через `aria-labelledby`. Фон за ними недоступен (`inert`); объявления для экранного диктора делаются из области вне `inert`. Tab не покидает окно, Escape закрывает его, если не выполняется операция, фокус возвращается на элемент, который его открыл. Явная кнопка «Закрыть» обязательна: нельзя полагаться только на Escape. Если фокусируемый элемент внутри окна исчезает или блокируется, фокус остаётся внутри окна.

## Опасные действия

«Отбросить» и «Применить без проверок» оформляются контуром и текстом `--color-danger`, подтверждаются отдельным шагом и показывают последствия до подтверждения. Акцентная основная кнопка для разрушающих действий не используется.

## Значки состояния

Статус всегда состоит из значка и подписи. Значки берутся из одного спрайта, цвет — `--color-success`, `--color-warning`, `--color-danger`, `--color-accent` или `--color-text-muted`; контраст значка не ниже 3:1. Неподтверждённый или устаревший результат — пунктирный круг, а не зелёная отметка.

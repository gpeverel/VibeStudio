# Инструкции для агентов

Перед работой прочитай [CLAUDE.md](CLAUDE.md): это общие правила проекта для всех агентов, включая обязательные проверки и e2e при закрытии этапов.

План P1–P8 и критерии приёмки находятся в [docs/IMPLEMENTATION-PLAN.md](docs/IMPLEMENTATION-PLAN.md). Перед реализацией прочитай раздел своего этапа и общий порядок e2e-приёмки. Выполняй только порученный этап или подэтап; следующие автоматически не начинай.
